# Kiran Seva Sansthan (KSS)

Towards a Sickle Cell-free Madhya Pradesh — screening, care, and dignity for tribal communities.

## 🌟 Overview

Kiran Seva Sansthan (KSS) is a bilingual sickle cell awareness, screening, and care initiative serving the tribal districts of Anuppur, Dindori, Mandla, Shahdol, Umaria, and Sidhi in Madhya Pradesh. 

This platform provides:
- **Donation Portal**: Secure support for sickle cell initiatives with 80G tax compliance.
- **Resource Library**: Multilingual PDF guides and awareness materials in Hindi and English.
- **Impact Tracking**: Transparency on screenings, lives touched, and outreach camps.

## 🛠️ Technology Stack

- **Frontend**: React + Vite + Tailwind CSS
- **UI Components**: Shadcn UI + Radix UI
- **Animations**: Framer Motion
- **Internationalization**: i18next (English & Hindi support)
- **Package Manager**: Bun

## 🚀 Getting Started

### Prerequisites

Ensure you have [Bun](https://bun.sh/) installed.

### Installation

```bash
bun install
```

### Development

```bash
bun dev
```

The application will be available at `http://localhost:8080`.

### Build

```bash
bun run build
```
